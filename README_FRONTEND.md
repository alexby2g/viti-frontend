# Frontend VITI Core

```bash
npm install
npm run dev
```

La URL de la API se configura en `.env`:

```env
VITE_API_URL=http://localhost:8000/api/v1
```

Rutas principales:

- `/configuracion-inicial`
- `/login`
- `/clientes`
- `/empresas`
- `/solicitudes`
- `/proyectos`
- `/aplicaciones`
- `/mantenimientos`
- `/archivos`
- `/reportes`
- `/solicitar/:token` para el cuestionario público del cliente.
